About this project

A marketing hub for a resort’s whole team

A private, invite-only marketing hub for a resort’s whole marketing team. It brings hotel bookings, restaurant covers, event sales, e-blasts, website, paid, social and the competition into one place, refreshed automatically every day, with an AI Advisor that says what to do next. I designed it, built it and run it.

The problem

The team was logging into 8+ systems, copying numbers into spreadsheets, and reading weekly reports that were already out of date by the time they arrived.

What I built

One place that pulls every source together every morning, compares it to last year, flags what needs attention, and suggests the next move, on desktop or phone.

My role

  • Design: the look, the pages and how the team moves through them
  • Build: every page, chart and the Advisor
  • Data pipelines: the daily pulls from each system
  • Security: invite-only access and per-person page permissions

The stack, in plain words

  • Hosted on Cloudflare
  • A private database for the numbers
  • Sign-in with one-time codes sent by email, no passwords
  • Data refreshes automatically every day
  • Code deployed from GitHub

This demo uses a made-up resort, Seacliff Resort & Spa, with made-up numbers. The real hub is private.
