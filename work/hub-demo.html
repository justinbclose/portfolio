    About this project

    One hub for a resort group’s whole marketing team

    A private, invite-only marketing hub. It brings hotel bookings, restaurant covers, event sales, e-blasts, website, paid, social and the competition into one place, refreshes itself every morning and every few hours, and has an AI Advisor that says what to do next. I designed it, built it and run it.

    The problem

    8+ separate logins, spreadsheets, and weekly reports that were stale by Monday.

    What I built

    One private hub that refreshes itself, compares everything to last year, flags what needs attention and suggests the next move, on desktop or phone.

    My role

    Product design, UX, front end, data pipelines, automation, security and deployment.

    How it works, in plain words

    • Hosted on Cloudflare
    • A private database for team notes and to-dos
    • Sign-in with emailed one-time codes, no passwords
    • Data refreshes automatically every day
    • Code changes are reviewed and deployed from GitHub, with preview versions before going live

    Integrations that keep it fresh

    Every morning (and every few hours for the fast-moving ones) the hub pulls read-only reports from each system through its API or a scheduled export:

    OPERAHotel system: rooms, revenue and pace on the books
    OpenTableRestaurant covers and holiday reservations
    Tripleseat + iVvyEvent sales pipeline, booked and hosted revenue
    Ascent360E-blast sends, opens, clicks and attributed bookings
    Google Analytics 4Website visits, booking-engine conversions, audiences
    Meta + Google AdsAd spend, clicks, bookings and return
    Meta Ad Library + Google Ads TransparencyThe comp set’s live ads
    InstagramFollowers, posts and Reels for us and the comp set
    OutlookTeam calendar, deadlines and sends
    Claude (Anthropic API)The AI Advisor, agent briefings and Ask

    Runs on Cloudflare (Workers, a private database and Access sign-in), deployed from GitHub.

    Privacy

    Totals only. No guest names, emails or card data are ever stored.

    Design decisions

    ■ ▲ ● ◆ Shape + colour + wordStatus always uses all three, so it works for colour-blind users.
    Every page says how fresh it isEach data source shows when it last updated, and stale ones turn amber.
    Phone firstMarketers check it between meetings, so every page works one-handed at 375px.
    Last year is always the yardstickEvery number is shown against the same time last year, not a target someone guessed.

    This demo uses a made-up resort group, Seacliff Collection, with made-up numbers. The real hub is private.
